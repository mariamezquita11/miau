# Temporizadores (Web)

App web minimalista y oscura para crear varios temporizadores.

Cómo usar:

- Abrir `index.html` en el navegador.
- Añadir nombre, minutos y segundos, luego `Añadir`.
- Usar `Iniciar/Pausa`, `Reiniciar` o `Eliminar` en cada temporizador.

Hecho con HTML/CSS/JS (sin dependencias).
